*Как быстро находить данные по произвольному ключу, отличать отсутствующий элемент от нулевого значения и собирать множества без дубликатов.*

Представьте, что в `BookmarkFlow` нужно посчитать, сколько закладок помечено каждым тегом (`"go"`, `"cli"`, `"docs"`). В паре параллельных слайсов `tagNames` и `tagCounts` для каждого нового тега придётся пробегать весь `tagNames` циклом от начала до конца. Слайс умеет обращаться к элементам только по числовому индексу `0, 1, 2`, а нам нужен поиск напрямую по осмысленному ключу — например, по строке `"go"`.

## Интуиция: словарь пар «ключ → значение»

В бумажном словаре не листают все страницы подряд с первой — сразу открывают нужную букву и читают значение. В программе нужна коллекция пар «ключ → значение»:

```text
  ключ (string)          значение (int)
  ─────────────          ──────────────
     "go"       ──────▶       4
     "cli"      ──────▶       2
     "docs"     ──────▶       1
```

В Go такую коллекцию называют **мапа, или словарь `map`**. Тип записывается как `map[K]V`, где `K` — тип ключа, `V` — тип значения (`map[string]int` сопоставляет строковым тегам счётчики).

Поиск, добавление и удаление по ключу работают почти мгновенно даже на десятках тысяч записей. Как устроены словари внутри с хешированием и коллизиями — разберём в Модуле 6, а внутреннее устройство рантайма Go — в Томе 5.

## Создание и базовые операции

Готовую к работе мапу создают через `make` или литерал:

```go
counts := make(map[string]int)     // пустая мапа
urlsByID := make(map[int]string, 64) // пустая с подсказкой ёмкости

statusText := map[int]string{
	200: "OK",
	404: "Not Found",
	500: "Internal Server Error",
}
empty := map[string]int{} // пустой литерал
```

Запись и обновление выглядят одинаково: `m[key] = value`. Число пар возвращает `len(m)`. Для удаления пары служит `delete(m, key)` — если ключа нет, функция ничего не делает и не падает. Встроенная `clear(m)` очищает все пары сразу, оставляя мапу готовой к новым записям (`len(m) == 0`).

## Чтение и идиома *comma ok*

Чтение отсутствующего ключа `m[key]` не роняет программу, а возвращает **нулевое значение** типа `V` (`0`, `""`, `false`). Для счётчиков это удобно: `counts[tag]++` работает сразу, без проверки.

Но возникает двусмысленность: если у нового тега `"archive"` счётчик равен `0`, то `counts["archive"]` и `counts["rust"]` вернут одинаковый `0`. Чтобы отличить реальный ноль от отсутствующего ключа, используют идиому **comma ok**:

```go
clicks, ok := counts["archive"]
if !ok {
	fmt.Println("Тег ещё не встречался")
} else {
	fmt.Println("Записей с тегом:", clicks)
}
```

Флаг `ok` равен `true`, если ключ есть в мапе, и `false` — если его нет. Часто проверку совмещают с `if`:

```go
if label, ok := statusText[404]; ok {
	fmt.Println("Статус 404:", label)
}
```

## Множество без дубликатов: `map[string]bool` и `map[string]struct{}`

Отдельного типа «множество» (*set*) в Go нет — его заменяет мапа, где важны только ключи:

1. **`map[string]bool`** — читаемый вариант для небольших списков: проверка выглядит как `if seen[tag]`.
2. **`map[string]struct{}`** — экономный вариант для крупных наборов. Пустая структура `struct{}` занимает **0 байт** памяти; добавляют через `seen[tag] = struct{}{}`, проверяют через `_, ok := seen[tag]`.

## Рабочий пример: подсчёт и очистка тегов

Соберём оба приёма в одну короткую программу на базе задач `BookmarkFlow`:

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	rawTags := []string{" Go ", "cli", "go", "docs", "CLI", "testing"}

	counts := make(map[string]int)
	unique := make(map[string]struct{})

	for _, raw := range rawTags {
		tag := strings.ToLower(strings.TrimSpace(raw))
		counts[tag]++
		unique[tag] = struct{}{}
	}

	// Зафиксируем тег с реальным значением 0, чтобы проверить comma ok
	counts["archive"] = 0

	for _, name := range []string{"go", "archive", "rust"} {
		n, ok := counts[name]
		fmt.Printf("тег %-8q -> count=%d ok=%t\n", name, n, ok)
	}

	delete(counts, "testing")
	delete(counts, "missing") // безопасно: ключа нет, паники не будет
	fmt.Println("Уникальных тегов:", len(unique), "| пар в counts:", len(counts))

	clear(counts)
	fmt.Println("После clear:", len(counts))
}
```

Запустим `go run .` и посмотрим на результат:

```text
тег "go"     -> count=2 ok=true
тег "archive" -> count=0 ok=true
тег "rust"   -> count=0 ok=false
Уникальных тегов: 4 | пар в counts: 4
После clear: 0
```

Обратите внимание на строки для `"archive"` и `"rust"`: обе вернули `count=0`, но флаг `ok` безошибочно их разделил. Без *comma ok* эти два состояния были бы неразличимы.

## Какие типы могут быть ключами мапы

Ключом `K` в `map[K]V` может стать **только сравнимый тип** — такой, значения которого можно проверять операторами `==` и `!=`. К ним относятся все числа, строки, `bool`, указатели и массивы фиксированной длины из сравнимых элементов (например, `[2]string`).

Слайсы, другие мапы и функции сравнивать через `==` нельзя, поэтому компилятор запретит использовать их как ключ:

```go
var bad map[[]string]int
// compile error: invalid map key type []string
```

Если ключом должна служить пара фиксированного размера — например, категория и тег, — используйте массив `[2]string` или структуру из сравнимых полей (её мы разберём через урок). Значением `V`, напротив, может быть абсолютно любой тип — хоть слайс (`map[string][]int`), хоть вложенная мапа.

> [!check] Проверь понимание
> Что выведет этот фрагмент?
> ```go
> m := map[string]int{"draft": 0}
> a, okA := m["draft"]
> b, okB := m["published"]
> fmt.Println(a, okA, b, okB)
> ```
>
> Выведет `0 true 0 false`. Ключ `"draft"` присутствует со значением `0`, поэтому `okA == true`. Ключа `"published"` в мапе нет, поэтому `m["published"]` возвращает нулевое значение `0` и `okB == false`.

## Практика

**Упражнение 1 (Базовое). Частота тегов.**  
Напишите функцию `countTags(tags []string) map[string]int`, которая нормализует каждый тег (`strings.ToLower(strings.TrimSpace(tag))`), пропускает пустые строки и возвращает мапу с числом вхождений каждого тега.

> [!solution] Показать решение
> ```go
> func countTags(tags []string) map[string]int {
> 	counts := make(map[string]int)
> 	for _, raw := range tags {
> 		tag := strings.ToLower(strings.TrimSpace(raw))
> 		if tag == "" {
> 			continue
> 		}
> 		counts[tag]++
> 	}
> 	return counts
> }
> ```
> Здесь мы сразу инициализируем мапу через `make`, отбрасываем пустые строки ранним `continue` и полагаемся на нулевое значение `int` в строке `counts[tag]++`.

**Упражнение 2 (Практическое). Уникальные теги с сохранением порядка.**  
Напишите функцию `uniqueTags(tags []string) []string`, которая принимает список тегов с повторами, нормализует их (нижний регистр, без пробелов по краям, без пустых) и возвращает слайс уникальных тегов **в порядке первого появления**. Используйте множество `map[string]struct{}`.

> [!solution] Показать решение
> ```go
> func uniqueTags(tags []string) []string {
> 	seen := make(map[string]struct{}, len(tags))
> 	out := make([]string, 0, len(tags))
> 	for _, raw := range tags {
> 		tag := strings.ToLower(strings.TrimSpace(raw))
> 		if tag == "" {
> 			continue
> 		}
> 		if _, ok := seen[tag]; ok {
> 			continue
> 		}
> 		seen[tag] = struct{}{}
> 		out = append(out, tag)
> 	}
> 	return out
> }
> ```
> Множество `seen` мгновенно отвечает на вопрос «видели ли мы этот тег раньше», а слайс `out` сохраняет исходный порядок появления.

**Упражнение 3 (Со звёздочкой \*). Что сломается?**  
Разработчик захотел посчитать, сколько закладок относится к каждой паре «домен + тег», и написал `var stats map[[]string]int`. Почему код не скомпилируется и как исправить тип ключа, не склеивая строки вручную?

> [!solution] Показать решение
> Слайс `[]string` не поддерживает сравнение через `==`, поэтому компилятор выдаст `invalid map key type []string`. Поскольку в паре ровно два элемента, замените слайс на массив фиксированной длины:
> ```go
> stats := make(map[[2]string]int)
> stats[[2]string{"go.dev", "docs"}]++
> ```
> Массив `[2]string` сравним поэлементно, поэтому спокойно работает ключом мапы и избавляет от хрупкой склейки строк вроде `"go.dev:" + "docs"`.
