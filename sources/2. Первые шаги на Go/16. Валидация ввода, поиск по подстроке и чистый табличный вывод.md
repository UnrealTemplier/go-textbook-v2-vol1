*Как нормализовать пользовательский ввод, искать закладки без учёта регистра и печатать ровную таблицу в терминале, не ломая кириллицу.*

Когда в `BookmarkFlow` всего две закладки, формат `#1 | Документация Go -> https://go.dev/doc` выглядит нормально. Но добавьте пятнадцать записей с короткими и длинными русскими названиями, введите в поиск `"spec"` вместо `"Spec"` или передайте в `delete` строку `"-5"` — и сырой прототип начнёт спотыкаться на каждом шагу.

В этом уроке подготовим три рабочих строительных блока из пакета `strings` и `fmt`, чтобы в следующей главе собрать полноценный консольный `BookmarkFlow`.

## 1. Нормализация и строгая валидация ввода

Пользовательский ввод из терминала почти всегда «грязный»: лишние пробелы, разный регистр букв, случайные знаки табуляции, неверные числа. Золотое правило бэкенда и CLI — **нормализовать и проверять ввод на самой границе программы**, до того как данные попадут в хранилище.

Посмотрим на четыре функции пакета `strings`, которые закрывают большинство задач валидации:

| Функция | Что делает | Пример |
|---|---|---|
| `strings.TrimSpace(s)` | Убирает пробелы, `\t`, `\n` с обоих краёв | `"  Go \n"` → `"Go"` |
| `strings.ToLower(s)` | Переводит все буквы (включая кириллицу) в нижний регистр | `"Блог Go"` → `"блог go"` |
| `strings.HasPrefix(s, p)` | Проверяет, начинается ли `s` с подстроки `p` | `HasPrefix("https://go.dev", "https://")` → `true` |
| `strings.Contains(s, sub)` | Проверяет, входит ли `sub` в `s` | `Contains("go.dev/ref/spec", "spec")` → `true` |

В прошлом уроке мы заметили тонкость: ссылка `"HTTPS://go.dev"` не проходила проверку `strings.HasPrefix(cleanURL, "https://")`. Исправить это просто — проверяем схему по версии в нижнем регистре:

```go
func hasHTTPPrefix(rawURL string) bool {
	lower := strings.ToLower(rawURL)
	return strings.HasPrefix(lower, "http://") || strings.HasPrefix(lower, "https://")
}
```

При этом саму строку `cleanURL` целиком в нижний регистр переводить **нельзя**: путь в URL после домена бывает чувствителен к регистру (например, `/wiki/Go_language` и `/wiki/go_language` — разные страницы). Проверку схемы делаем на `lower`, а сохраняем исходный `cleanURL`.

Аналогично валидируется идентификатор для команды `delete <id>`: недостаточно проверить, что `strconv.Atoi` не вернул ошибку — нужно ещё отсечь `0` и отрицательные числа:

```go
func parseID(raw string) (int, error) {
	id, err := strconv.Atoi(strings.TrimSpace(raw))
	if err != nil || id <= 0 {
		return 0, fmt.Errorf("некорректный id %q", raw)
	}
	return id, nil
}
```

## 2. Поиск по подстроке без учёта регистра

Если пользователь сохранил закладку `"Go Spec"` с адресом `"https://go.dev/ref/spec"`, а ищет `"spec"` или `"ДОКУМЕНТАЦИЯ"`, точное сравнение `==` не найдёт ничего.

В Go регистронезависимый поиск по подстроке в названии **или** URL записывается в три прозрачные строки:

```go
func matchesQuery(title, rawURL, query string) bool {
	q := strings.ToLower(strings.TrimSpace(query))
	if q == "" {
		return true // пустой запрос совпадает со всеми записями
	}
	return strings.Contains(strings.ToLower(title), q) ||
		strings.Contains(strings.ToLower(rawURL), q)
}
```

Заметьте аккуратную обработку граничного случая: если пользователь передал пустой запрос `""` или `"   "`, функция возвращает `true` (показать все закладки), а не пустой экран.

А если сравнить две строки на полное равенство без учёта регистра (например, имя команды `"ADD"` и `"add"`), в Go есть ещё более точная стандартная функция `strings.EqualFold(a, b)` — она корректно работает со сложными правилами регистра Unicode.

## 3. Чистый табличный вывод и ловушка ширины колонок

В `project/step02/cli.go` список закладок выводится единым форматом колонок:

```go
fmt.Printf("%-4d | %-24s | %s\n", id, title, url)
```

Разберём этот шаблон:
* `%-4d` — номер шириной минимум 4 символа, прижатый к левому краю.
* `%-24s` — название шириной минимум 24 символа, прижатое к левому краю.
* `%s` — последняя колонка (URL) без жёсткой ширины, чтобы длинные ссылки не обрезались и оставались кликабельными в терминале.

Но что случится, если название закладки длиннее 24 символов — например, `"Руководство по стандартной библиотеке Go"` (40 символов)? Формат `%-24s` задаёт **минимальную**, а не максимальную ширину, поэтому длинная строка **вытолкнет** разделитель `|` далеко вправо, и таблица разъедется!

Соединим нашу функцию безопасного усечения по рунам `truncate` из урока 9 с шаблонным выводом:

```go
package main

import (
	"fmt"
	"strings"
	"unicode/utf8"
)

func truncateRunes(s string, maxRunes int) string {
	if maxRunes <= 0 {
		return ""
	}
	if utf8.RuneCountInString(s) <= maxRunes {
		return s
	}
	if maxRunes <= 3 {
		// Если лимит слишком мал для "...", режем без многоточия
		count := 0
		for byteIdx := range s {
			if count == maxRunes {
				return s[:byteIdx]
			}
			count++
		}
	}
	count := 0
	for byteIdx := range s {
		if count == maxRunes-3 {
			return s[:byteIdx] + "..."
		}
		count++
	}
	return s
}

func printTable(ids []int, titles, urls []string) {
	if len(ids) == 0 {
		fmt.Println("Ничего не найдено.")
		return
	}
	fmt.Printf("%-4s | %-24s | %s\n", "ID", "Название", "URL")
	fmt.Println(strings.Repeat("-", 64))
	for i := range len(ids) {
		shortTitle := truncateRunes(titles[i], 24)
		fmt.Printf("%-4d | %-24s | %s\n", ids[i], shortTitle, urls[i])
	}
}

func main() {
	ids := []int{1, 2, 15}
	titles := []string{
		"Go Spec",
		"Документация Go",
		"Руководство по стандартной библиотеке Go",
	}
	urls := []string{
		"https://go.dev/ref/spec",
		"https://go.dev/doc",
		"https://pkg.go.dev/std",
	}
	printTable(ids, titles, urls)
}
```

Вывод программы — ровный, как по линейке, и с чистой кириллицей:

```text
ID   | Название                 | URL
----------------------------------------------------------------
1    | Go Spec                  | https://go.dev/ref/spec
2    | Документация Go          | https://go.dev/doc
15   | Руководство по станда... | https://pkg.go.dev/std
```

Обратите внимание на маленькую, но приятную деталь: `strings.Repeat("-", 64)` строит линию-разделитель из 64 дефисов без ручного копирования и без цикла.

> [!check] Проверь понимание
> Почему в `truncateRunes("Руководство...", 24)` мы считали символы через `utf8.RuneCountInString` и цикл `for byteIdx := range s`, а не просто написали `s[:21] + "..."`?
>
> Потому что каждая русская буква в UTF-8 занимает 2 байта. Срез `s[:21]` отрезал бы не 21 букву, а 21 байт — и попал бы точно в середину 11-й буквы, выдав битый символ ``. Цикл `range` шагает строго по границам рун.
