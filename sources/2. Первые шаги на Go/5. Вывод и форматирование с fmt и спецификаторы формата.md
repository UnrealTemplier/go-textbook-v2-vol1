*Как управлять выводом текста в терминал и собирать форматированные строки с помощью пакета `fmt` и спецификаторов формата.*

В предыдущем уроке мы печатали чек вызовом `fmt.Println("К оплате:", rub, "руб.", kop, "коп.")`. Стоит копейкам оказаться равными `5` — и пользователь увидит `54 руб. 5 коп.` вместо аккуратного `54.05 руб.`. А если выводить список закладок, столбцы сразу разъедутся лесенкой.

Для точного контроля над текстом в стандартной библиотеке Go живёт пакет **`fmt`** (*format*). За пять минут вы освоите четыре его главные функции и набор шаблонов, который закроет 95% задач вывода.

## Четыре рабочие функции пакета `fmt`

Пакет `fmt` устроен симметрично — достаточно запомнить два суффикса и один префикс:

| Функция | Перенос строки | Что делает |
|---|---|---|
| `fmt.Print(...)` | Нет | Печатает значения подряд в стандартный вывод (`stdout`) |
| `fmt.Println(...)` | Да (`\n`) | Печатает значения через пробел и переводит строку |
| `fmt.Printf(format, ...)` | Нет (пишите `\n` сами) | Подставляет значения в шаблон и печатает в `stdout` |
| `fmt.Sprintf(format, ...)` | Нет | Делает то же самое, но **возвращает готовую `string`**, ничего не печатая |

Обратите внимание на `fmt.Sprintf`: приставка `S` (*String*) означает, что результат собирается в строку, а не уходит на экран. Именно с `fmt.Sprintf` мы будем собирать аккуратные строки закладок и тексты ошибок в `BookmarkFlow`.

## Спецификаторы формата (*formatting verbs*)

В `fmt.Printf` и `fmt.Sprintf` первый аргумент — это строка-шаблон. Места подстановки помечаются знаком `%` и буквой — **спецификатором формата** (*verb*):

```go
package main

import "fmt"

func main() {
	id := 7
	title := "Документация Go"
	latencyMs := 14.378
	ok := true

	fmt.Printf("ID: %d | Название: %s | Время: %.2f мс | Доступен: %t\n",
		id, title, latencyMs, ok)
	fmt.Printf("В кавычках: %q\n", title)
	fmt.Printf("Универсально: %v | Тип: %T\n", latencyMs, latencyMs)
}
```

Вывод программы:

```text
ID: 7 | Название: Документация Go | Время: 14.38 мс | Доступен: true
В кавычках: "Документация Go"
Универсально: 14.378 | Тип: float64
```

Вот шпаргалка по спецификаторам, которыми вы будете пользоваться каждый день:

| Спецификатор | Что форматирует | Пример вывода |
|---|---|---|
| `%d` | Целое число в десятичной системе | `42` |
| `%x` / `%X` | Целое в hex (строчные / заглавные) | `2a` / `2A` |
| `%b` | Целое в двоичной записи | `101010` |
| `%f` / `%.2f` | Дробное число (с точностью 2 знака) | `14.378000` / `14.38` |
| `%s` | Строка как есть | `Документация Go` |
| `%q` | Строка в двойных кавычках с экранированием | `"Документация Go"` |
| `%t` | Логическое `bool` | `true` / `false` |
| `%v` | Значение любого типа в формате по умолчанию | `14.378` |
| `%T` | Имя типа переменной (полезно для отладки) | `float64` |
| `%%` | Буквальный знак процента `%` | `%` |

Особо полюбите **`%q`** (*quoted*). Если в пользовательской строке затесался лишний пробел в конце или невидимый символ перевода строки `\n`, `%s` скроет проблему, а `%q` мгновенно её проявит: `"https://go.dev\n"` вместо обманчивого `https://go.dev`.

## Ширина, выравнивание и ведущие нули

Между `%` и буквой спецификатора можно поставить модификаторы ширины и выравнивания:

* `%02d` — целое шириной минимум 2 символа, дополненное слева **нулями** (`5` → `05`, идеально для копеек, минут и дат).
* `%6d` — целое шириной минимум 6 символов, выровненное **по правому краю** (`42` → `    42`).
* `%-16s` — строка шириной минимум 16 символов, выровненная **по левому краю** (`-` означает «прижать влево»).

Посмотрим, как одной строкой шаблона получается ровная консольная таблица:

```go
package main

import "fmt"

func main() {
	fmt.Printf("%-4s | %-18s | %8s\n", "ID", "Сервис", "Ответ")
	fmt.Printf("%-4d | %-18s | %6.1f ms\n", 1, "auth-api", 12.4)
	fmt.Printf("%-4d | %-18s | %6.1f ms\n", 12, "bookmark-flow", 148.05)

	// Копейки с ведущим нулём
	totalKop := 5405
	check := fmt.Sprintf("%d.%02d руб.", totalKop/100, totalKop%100)
	fmt.Println("Чек:", check)
}
```

Вывод:

```text
ID   | Сервис             |    Ответ
1    | auth-api           |   12.4 ms
12   | bookmark-flow      |  148.1 ms
Чек: 54.05 руб.
```

Обратите внимание на последнюю строку: `%.1f` **округлило** `148.05` до `148.1`, а `%02d` превратило `5` копеек в `05`.

## Ловушка несоответствия спецификатора и `go vet`

Что произойдёт, если передать в `%d` строку вместо числа или забыть аргумент? Компилятор Go пропустит такой код, но в выводе появится явная диагностическая метка `fmt`:

```go
fmt.Printf("ID: %d\n", "abc") // Вывод: ID: %!d(string=abc)
fmt.Printf("ID: %d %s\n", 7)  // Вывод: ID: 7 %!s(MISSING)
```

Чтобы ловить такие ошибки **до** запуска программы, в Go встроен статический анализатор **`go vet`**:

```bash
go vet ./...
```

На код выше он мгновенно отчитается:

```text
./main.go:6:2: fmt.Printf format %d has arg "abc" of wrong type string
./main.go:7:2: fmt.Printf format %s reads arg #2, but call has 1 arg
```

Приучите себя запускать `go vet ./...` — это бесплатный ревьюер, который находит опечатки в шаблонах `Printf`, недостижимый код и тонкие ошибки за доли секунды.

Ещё одна частая мелочь: `fmt.Printf` **не добавляет `\n` сам**. Если вы забыли `\n` в конце формата, следующий вывод терминала (или приглашение командной строки) приклеится в ту же строку.

> [!check] Проверь понимание
> Чем отличается вывод `fmt.Printf("%s\n", "  go\t")` от `fmt.Printf("%q\n", "  go\t")`?
>
> `%s` напечатает два пробела, слово `go` и невидимую табуляцию — глазами легко подумать, что строка чистая. `%q` заключит значение в кавычки и покажет управляющие символы явно: `"  go\t"`.

**Упражнение 3 (Со звёздочкой \*). Что сломается и что скажет `go vet`?**  
В этом фрагменте три ошибки форматирования. Найдите их, проверьте через `go vet` и исправьте так, чтобы выводилась строка `Сервер #03: загрузка 75% (статус: "ready")`:

```go
package main

import "fmt"

func main() {
	id := 3
	load := 75
	status := "ready"
	fmt.Printf("Сервер #%02s: загрузка %d% (статус: %q)", id, load)
}
```

> [!solution] Показать решение
> Три ошибки:
> 1. `%02s` для целого `id` — нужен `%02d`.
> 2. Одиночный `%` после `%d` ломает разбор шаблона — буквальный процент пишется как `%%`.
> 3. Забыт третий аргумент `status` для `%q` (плюс отсутствует `\n` в конце строки).
>
> Исправленный вызов:
> ```go
> fmt.Printf("Сервер #%02d: загрузка %d%% (статус: %q)\n", id, load, status)
> ```
