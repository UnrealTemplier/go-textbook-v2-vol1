# Сквозной проект · Том 1 · `BookmarkFlow`

**Проект:** `BookmarkFlow` — консольный менеджер закладок, который шаг за шагом через модули Тома 1 вырастает в полноценный HTTP-сервис на JSON-файлах с конкурентной проверкой ссылок, тестами и `Dockerfile`.  
**Целевая версия Go:** `Go 1.24` *(только стандартная библиотека — 0 внешних зависимостей, 100% автономные тесты)*.

## Карта шагов

| Каталог | Модуль Тома 1 | Что добавляется на этом шаге |
|---|---|---|
| `step01/` | Модуль 2 (гл. 15) | Валидация ввода, добавление закладок в памяти и форматированный вывод |
| `step02/` | Модуль 2 (гл. 17) | Полноценный CLI в памяти (`add`, `list`, `search`, `delete`) и проверка ошибок `errors.Is` |
| `step03/` | Модуль 3 (гл. 18) | Структура `Bookmark`, методы и сохранение/загрузка JSON-файла |
| `step04/` | Модуль 3 (гл. 19) | Интерфейс `Store`, реализации `MemoryStore` и `FileStore`, контрактные unit-тесты |
| `step05/` | Модуль 4 (гл. 30) | Потокобезопасный `SafeStore` (`sync.RWMutex`) и конкурентный чекер ссылок (Worker Pool, `WaitGroup`, `context`, `slog`) |
| `step06/` | Модуль 5 (гл. 33) | Атомарная перезапись JSON (`tmp` + `os.Rename`) и мини-TCP-сервер на пакете `net` |
| `step07/` | Модуль 6 (гл. 11) | Инвертированный индекс по тегам (`TagIndex`), бинарный поиск по ID и сортировка `slices.SortFunc` |
| `final/` | Модуль 7 (гл. 20) | HTTP-бэкенд на `net/http` (`ServeMux` Go 1.22+), CRUD JSON API, middleware, Graceful Shutdown, `httptest`, `Dockerfile` |

## Проверка и запуск

Запуск всех тестов (включая детектор гонок):
```bash
go test -race ./...
```

Запуск финального HTTP-сервиса локально:
```bash
go run ./final/cmd/bookmarkflow -addr :8080 -data /tmp/bookmarks.json
```

Сборка Docker-образа (из каталога `project/`):
```bash
docker build -f final/Dockerfile -t bookmarkflow:vol1 .
```
