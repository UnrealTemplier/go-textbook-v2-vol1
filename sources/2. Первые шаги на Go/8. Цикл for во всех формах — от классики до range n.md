*Почему в Go нет `while` и `do-while`, как пользоваться всеми пятью формами `for` — включая `for i := range n` из Go 1.22+ — и как правильно перебирать руны в UTF-8.*

В других языках программист держит в голове три-четыре вида циклов: `for`, `while`, `do-while`, `foreach`. В Go слово всего одно — **`for`**. Оказалось, что если просто разрешить опускать ненужные части заголовка `for`, все остальные ключевые слова становятся лишними.

Давайте посмотрим на все пять рабочих форм `for` и одну важную тонкость, которая связывает циклы со строками UTF-8 из шестого урока.

## Пять форм цикла `for`

### 1. Классический счётчик (три части: инициализация; условие; шаг)

```go
sum := 0
for i := 1; i <= 5; i++ {
	sum += i
}
fmt.Println("Сумма 1..5:", sum) // 15
```

Как и в `if`, круглые скобки вокруг заголовка не ставятся, а переменная `i` видна только внутри цикла. Обратите внимание на `i++`: в Go инкремент `++` и декремент `--` — это **инструкции**, а не выражения, поэтому писать `j := i++` или `++i` нельзя (так авторы убрали из языка знаменитый класс загадок про порядок вычисления из Си).

### 2. Цикл по условию (аналог `while`)

Уберите инициализацию и шаг — и `for` работает точно как `while`:

```go
// Сколько раз нужно удвоить 1 КБ, чтобы превысить 100 КБ?
sizeKB := 1
steps := 0
for sizeKB <= 100 {
	sizeKB *= 2
	steps++
}
fmt.Printf("За %d шагов выросли до %d КБ\n", steps, sizeKB) // За 7 шагов выросли до 128 КБ
```

### 3. Бесконечный цикл + `break` и `continue`

Уберите и условие — получите цикл, который крутится до явного `break` (выйти из цикла) или `return` (выйти из функции). Пропустить оставшуюся часть текущего шага и перейти к следующему позволяет `continue`:

```go
attempts := 0
for {
	attempts++
	if attempts == 2 {
		continue // пропускаем вторую попытку
	}
	fmt.Println("Попытка #", attempts)
	if attempts >= 3 {
		break // выходим из бесконечного цикла
	}
}
```

### 4. Современный счётчик `for i := range n` (Go 1.22+)

Начиная с **Go 1.22**, перебрать целые числа от `0` до `n-1` можно предельно коротко и без риска ошибиться в знаке `<` или `<=`:

```go
for i := range 4 {
	fmt.Printf("Повтор #%d\n", i+1)
}
```

Вывод:

```text
Повтор #1
Повтор #2
Повтор #3
Повтор #4
```

Если само значение счётчика не нужно (например, просто повторить действие 3 раза), переменную можно вообще опустить: `for range 3 { fmt.Println("ping") }`. Если `n <= 0`, цикл просто не выполнится ни разу.

### 5. Обход строки UTF-8 по рунам: `for idx, r := range s`

В [[6. Строки, байты, руны и UTF-8 в Go]] мы столкнулись с проблемой: обычный индекс `s[i]` читает отдельные байты и режет кириллицу пополам. Конструкция **`for ... range`** по строке решает эту задачу на уровне языка — она сама декодирует UTF-8 символ за символом:

```go
package main

import "fmt"

func main() {
	word := "Go! Мир"

	for byteIdx, r := range word {
		fmt.Printf("байт=%d | руна=%c | код=%U\n", byteIdx, r, r)
	}
}
```

Посмотрите на столбец `байт=`:

```text
байт=0 | руна=G | код=U+0047
байт=1 | руна=o | код=U+006F
байт=2 | руна=! | код=U+0021
байт=3 | руна=  | код=U+0020
байт=4 | руна=М | код=U+041C
байт=6 | руна=и | код=U+0438
байт=8 | руна=р | код=U+0440
```

Обратите внимание на прыжок `4 → 6 → 8`. Первый индекс в `for byteIdx, r := range word` — это **байтовое смещение** начала текущей руны в строке, а не порядковый номер буквы. Поэтому для ASCII-символов шаг равен `1`, а для двухбайтовых русских букв — `2`. Если байтовый индекс не нужен, его отбрасывают пустым идентификатором `_`: `for _, r := range word`.

## Выход из вложенного цикла: метки (*labels*)

Обычный `break` выходит только из **самого внутреннего** цикла. Если у вас два вложенных цикла и нужно прервать оба сразу (например, вы нашли первое совпадение в сетке), повесьте на внешний цикл метку:

```go
search:
for row := range 5 {
	for col := range 5 {
		if row*col == 6 {
			fmt.Printf("Нашли: row=%d, col=%d\n", row, col)
			break search // выходим сразу из внешнего цикла
		}
	}
}
```

Это чище и надёжнее, чем заводить искусственный булев флаг `found := false` и проверять его после каждого внутреннего цикла.

> [!check] Проверь понимание
> Сколько раз выполнится тело цикла `for i, r := range "Привет"` и какое значение будет у `i` на **последней** итерации?
>
> Тело выполнится **6 раз** (по числу рун). Каждая из шести кириллических букв занимает 2 байта, поэтому `i` примет значения `0, 2, 4, 6, 8, 10` — на последней итерации `i == 10`, а `r == 'т'`.

## Практика

**Упражнение 1 (Базовое). Проследи вывод (Code Tracing).**  
Определите без запуска, что выведет программа:

```go
package main

import "fmt"

func main() {
	total := 0
	for i := range 6 {
		if i%2 == 0 {
			continue
		}
		total += i
	}
	fmt.Println(total)
}
```

> [!solution] Показать решение
> Вывод: **`9`**.
> `for i := range 6` перебирает `0, 1, 2, 3, 4, 5`. Чётные числа (`0, 2, 4`) пропускаются через `continue`, а нечётные суммируются: `1 + 3 + 5 = 9`.

**Упражнение 2 (Практическое). Безопасная обрезка строки по рунам.**  
Напишите программу, которая принимает длинный заголовок `title := "Руководство по стандартной библиотеке Go"` и с помощью цикла `for byteIdx, r := range title` находит байтовую границу ровно первых `12` рун, после чего выводит аккуратно обрезанный заголовок с многоточием `"..."` (без единого битого байта ``).

> [!solution] Показать решение
> ```go
> package main
>
> import "fmt"
>
> func main() {
> 	title := "Руководство по стандартной библиотеке Go"
> 	maxRunes := 12
>
> 	count := 0
> 	cutAt := len(title)
> 	for byteIdx := range title {
> 		if count == maxRunes {
> 			cutAt = byteIdx
> 			break
> 		}
> 		count++
> 	}
>
> 	result := title
> 	if cutAt < len(title) {
> 		result = title[:cutAt] + "..."
> 	}
> 	fmt.Println(result) // Вывод: Руководство ...
> }
> ```
> Хитрость в том, что `byteIdx` из `range` **всегда** указывает на корректное начало очередной руны в UTF-8. Когда счётчик доходит до `12`, `byteIdx` оказывается точной байтовой границей сразу после 12-го символа — резать `title[:cutAt]` полностью безопасно.

**Упражнение 3 (Со звёздочкой \*). Что сломается?**  
В этом коде три ошибки: две поймает компилятор, а третья приведёт к бесконечному циклу. Найдите все три:

```go
package main

import "fmt"

func main() {
	count := 3
	while count > 0 {
		fmt.Println("Обратный отсчёт:", count)
		count = count--
	}
}
```
И отдельно подумайте: почему цикл `for i := uint8(3); i >= 0; i-- { fmt.Println(i) }` никогда не остановится?

> [!solution] Показать решение
> В первом фрагменте:
> 1. В Go нет ключевого слова `while` — нужно `for count > 0`.
> 2. `count--` — это инструкция, а не выражение, поэтому `count = count--` не скомпилируется; нужно просто `count--`.
>
> Во втором фрагменте: `uint8` не может быть отрицательным! После `i == 0` шаг `i--` переполняет беззнаковый байт до **`255`**, условие `255 >= 0` остаётся истинным — цикл становится бесконечным. Это ещё одна причина использовать обычный знаковый `int` для счётчиков циклов.
