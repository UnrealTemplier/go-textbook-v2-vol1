*Зачем поверх `io.Reader` и `io.Writer` ставят буфер в памяти, как безопасно читать потоки построчно через `bufio.Scanner` и почему забытый `Flush` молча теряет данные.*

Допустим, `BookmarkFlow` экспортирует 100 000 закладок в текстовый файл — по одной короткой строке на запись. Если на каждую строку вызывать `file.Write`, программа попросит операционную систему выполнить запись на диск сто тысяч раз подряд. Каждое обращение к ядру ОС стоит микросекунды накладных расходов: вместо пары миллисекунд экспорт растянется на сотни.

То же происходит при чтении: разбить поток сырых байтов из `io.Reader` на отдельные строки вручную неудобно, потому что очередной `Read(buf)` легко разрежет строку ровно посередине слова.

Обе задачи решает пакет `bufio` (*buffered I/O* — буферизованный ввод-вывод).

## Честная модель: накопитель между программой и ОС

`bufio` встаёт тонкой прослойкой между вашим кодом и любым `io.Reader` или `io.Writer`. Внутри него живёт обычный байтовый слайс — по умолчанию размером **4 КБ** (`4096` байтов).

```text
Без буфера:
  Write("line1\n") --> [вызов ОС]
  Write("line2\n") --> [вызов ОС]   (100 000 обращений к ОС)

С bufio.Writer:
  Write("line1\n") --\
  Write("line2\n") ---> [буфер 4 КБ в RAM] --(когда заполнен или Flush)--> [1 вызов ОС]
  Write("line3\n") --/
```

При записи `bufio.Writer` накапливает мелкие порции в RAM. Когда 4 КБ заполняются — или вы вызываете `Flush()` — весь блок уходит в базовый `io.Writer` одним обращением. Копирование байтов в памяти занимает наносекунды, а обращение к диску через ОС — в сотни и тысячи раз дольше. При чтении `bufio.Reader` и `bufio.Scanner` делают обратное: забирают крупный кусок за один раз и раздают строки из памяти. *(Механику системных вызовов ядра разберём в Модуле 5.)*

## Построчное чтение: `bufio.Scanner`

Для построчного разбора текста в Go берут `bufio.Scanner`:

```go
scanner := bufio.NewScanner(r)
for scanner.Scan() {
	line := scanner.Text()
	// строка без завершающего '\n' или '\r\n'
}
if err := scanner.Err(); err != nil {
	return err
}
```

Три главных правила `bufio.Scanner`:

1. `Scan()` переходит к следующей строке (отрезая `\n` и `\r\n`) и возвращает `true`, пока есть данные.
2. `Text()` возвращает копию строки как `string`. Метод `Bytes()` избегает копирования, но его срез перезаписывается на следующем `Scan()`.
3. **Всегда проверяйте `scanner.Err()` после цикла.** Цикл обрывается и на нормальном `io.EOF`, и на ошибке чтения. Без проверки `scanner.Err()` программа молча проглотит сбой.

Разделитель можно поменять до первого `Scan()` — например, `scanner.Split(bufio.ScanWords)` переключит сканер на чтение по словам.

### Лимит токена 64 КБ и `scanner.Buffer`

По умолчанию максимальная длина одной строки — **64 КБ** (`bufio.MaxScanTokenSize = 65536` байтов). На более длинной строке `Scan()` вернёт `false`, а `scanner.Err()` — ошибку `bufio.Scanner: token too long`. Лимит расширяют до цикла методом `Buffer(buf, maxCapacity)`:

```go
buf := make([]byte, 0, 64*1024)
scanner.Buffer(buf, 1024*1024) // строки до 1 МБ
```

Для строк произвольной длины (десятки мегабайт) вместо `Scanner` берите `bufio.Reader` с `ReadString('\n')`.

## Буферизованная запись: `bufio.Writer` и обязательный `Flush`

Чтобы ускорить массовую запись строк, оберните любой `io.Writer` в `bufio.NewWriter(w)`:

```go
package main

import (
	"bufio"
	"bytes"
	"fmt"
	"strings"
)

func filterBookmarks(src string) (string, int, error) {
	scanner := bufio.NewScanner(strings.NewReader(src))
	var out bytes.Buffer
	writer := bufio.NewWriter(&out)

	kept := 0
	for scanner.Scan() {
		line := strings.TrimSpace(scanner.Text())
		if line == "" || strings.HasPrefix(line, "#") {
			continue
		}
		if _, err := writer.WriteString(line + "\n"); err != nil {
			return "", 0, err
		}
		kept++
	}
	if err := scanner.Err(); err != nil {
		return "", 0, err
	}
	if err := writer.Flush(); err != nil {
		return "", 0, err
	}
	return out.String(), kept, nil
}

func main() {
	raw := "# экспорт закладок\nhttps://go.dev\n\nhttps://pkg.go.dev\n"
	cleaned, count, err := filterBookmarks(raw)
	if err != nil {
		fmt.Println("ошибка:", err)
		return
	}
	fmt.Printf("Сохранено строк: %d\n%s", count, cleaned)
}
```

Вывод терминала:

```text
Сохранено строк: 2
https://go.dev
https://pkg.go.dev
```

Здесь `bufio.Scanner` и `bufio.Writer` работают в паре: первый аккуратно режет вход на строки, второй собирает очищенные записи в буфер. Оба опираются исключительно на `io.Reader` и `io.Writer`, поэтому функция `filterBookmarks` одинаково легко переносится на реальные файлы.

## Подводные камни

**Ловушка 1. Забытый `writer.Flush()`.**  
Уберите строку `if err := writer.Flush(); err != nil` из примера выше — и программа **не выдаст ни одной ошибки**, но переменная `cleaned` окажется пустой строкой `""`. Все 34 байта так и остались лежать в 4-килобайтном буфере `writer` в памяти и исчезли при выходе из функции.

> [!warning] Проверяйте ошибку `Flush()`
> Не ограничивайтесь `defer writer.Flush()`: именно в момент `Flush()` данные физически уходят в файл или другой приёмник, и именно здесь может всплыть ошибка нехватки места на диске. Всегда проверяйте возвращённую `err`.

**Ловушка 2. Срез из `scanner.Bytes()` хранят без копии.**  
Слайс, который возвращает `scanner.Bytes()`, указывает прямо на внутренний буфер сканера. Если сложить его в `lines = append(lines, scanner.Bytes())`, к концу цикла все элементы окажутся испорчены последующими строками. Нужна копия — используйте `scanner.Text()` или `bytes.Clone(scanner.Bytes())`.

> [!check] Проверь понимание
> Программа записала 500 байтов в `bufio.NewWriter(f)`, проверила `err` после `WriteString`, а затем сразу закрыла файл `f.Close()` без `Flush()`. Сколько байтов окажется в файле?
>
> Ноль байтов. Поскольку 500 байтов меньше стандартного буфера в 4096 байтов, `bufio.Writer` ни разу не сбрасывал буфер в `f`. Закрытие `f` не знает о буфере поверх него.

## Практика

**Упражнение 1 (Базовое). Проследи ошибку длинной строки.**  
Что выведет код ниже? Почему цикл завершится без вывода строки?

```go
longLine := strings.Repeat("a", 70_000)
sc := bufio.NewScanner(strings.NewReader(longLine))
count := 0
for sc.Scan() {
	count++
}
fmt.Println(count, sc.Err())
```

> [!solution] Показать решение
> Вывод: `0 bufio.Scanner: token too long`.  
> Длина строки 70 000 байтов превышает стандартный лимит `bufio.MaxScanTokenSize` (65 536 байтов). Первый же вызов `sc.Scan()` вернёт `false`, а причину покажет `sc.Err()`. Чтобы прочитать такую строку, нужно до цикла вызвать `sc.Buffer(make([]byte, 0, 64*1024), 128*1024)`.

**Упражнение 2 (Практическое). Нумерация непустых строк.**  
Напишите функцию `NumberLines(r io.Reader, w io.Writer) error`, которая читает текст из `r` через `bufio.Scanner`, пропускает пустые строки (после `strings.TrimSpace`) и записывает оставшиеся в `w` через `bufio.Writer` в формате `"1: <строка>\n"`, `"2: <строка>\n"`. Не забудьте проверить `scanner.Err()` и `writer.Flush()`.

> [!solution] Показать решение
> ```go
> package main
>
> import (
> 	"bufio"
> 	"fmt"
> 	"io"
> 	"os"
> 	"strings"
> )
>
> func NumberLines(r io.Reader, w io.Writer) error {
> 	sc := bufio.NewScanner(r)
> 	bw := bufio.NewWriter(w)
>
> 	num := 0
> 	for sc.Scan() {
> 		line := strings.TrimSpace(sc.Text())
> 		if line == "" {
> 			continue
> 		}
> 		num++
> 		if _, err := fmt.Fprintf(bw, "%d: %s\n", num, line); err != nil {
> 			return err
> 		}
> 	}
> 	if err := sc.Err(); err != nil {
> 		return err
> 	}
> 	return bw.Flush()
> }
>
> func main() {
> 	in := strings.NewReader("go.dev\n   \npkg.go.dev\n")
> 	if err := NumberLines(in, os.Stdout); err != nil {
> 		fmt.Fprintln(os.Stderr, err)
> 	}
> 	// Вывод:
> 	// 1: go.dev
> 	// 2: pkg.go.dev
> }
> ```
> `fmt.Fprintf` пишет напрямую в буферизованный `bw`, а финальный `return bw.Flush()` гарантирует сброс хвоста и возврат возможной ошибки записи.

**Упражнение 3 (Со звёздочкой \*). Подсчёт слов с `bufio.ScanWords`.**  
Напишите функцию `CountWords(r io.Reader) (int, error)`, которая считает количество слов в произвольном потоке с помощью `bufio.Scanner` и разделителя `bufio.ScanWords`. Проверьте её на тексте с несколькими пробелами, табуляциями и переносами строк.

> [!solution] Показать решение
> ```go
> package main
>
> import (
> 	"bufio"
> 	"fmt"
> 	"io"
> 	"strings"
> )
>
> func CountWords(r io.Reader) (int, error) {
> 	sc := bufio.NewScanner(r)
> 	sc.Split(bufio.ScanWords)
>
> 	total := 0
> 	for sc.Scan() {
> 		total++
> 	}
> 	if err := sc.Err(); err != nil {
> 		return 0, err
> 	}

> }
>
> func main() {

> ```
> `bufio.ScanWords` автоматически пропускает любые последовательности пробельных символов (пробелы, табуляции, переводы строк) и не требует загружать весь текст в память через `strings.Fields`.
