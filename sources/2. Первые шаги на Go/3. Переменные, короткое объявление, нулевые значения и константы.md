*Как объявлять переменные через `var` и `:=`, почему в Go нет «мусорных» неинициализированных значений и чем константы отличаются от обычных переменных.*

В языке Си стоит объявить локальную переменную `int count;` и забыть записать туда число — и в ней окажется случайный мусор, оставшийся в ячейке памяти от предыдущего вызова функции. В Python, наоборот, переменную нельзя создать без значения, зато её тип может внезапно смениться посреди программы с числа на строку.

Go выбрал третий, предельно предсказуемый путь: **строгие статические типы** плюс **гарантированные нулевые значения** для каждой новой переменной. Разберём, как это работает на практике.

## Переменная как именованная ячейка памяти

В Прологе мы представляли оперативную память как длинный ряд пронумерованных байтов. Переменная в Go — это просто **удобное имя** для участка памяти фиксированного размера и **фиксированного типа**.

```text
Имя: port         Имя: host              Имя: tlsEnabled
Тип: int          Тип: string            Тип: bool
+----------+      +----------------+     +-------+
|   8080   |      | "localhost"    |     | true  |
+----------+      +----------------+     +-------+
```

Тип задаётся один раз при объявлении и никогда не меняется. Если `port` имеет тип `int`, записать туда строку `"8080"` компилятор не позволит — он поймает ошибку до запуска программы.

## Два способа объявить переменную: `var` и `:=`

В Go есть полная форма `var` и короткая `:=`. Посмотрим на них рядом:

```go
package main

import "fmt"

// На уровне пакета (вне функций) работает только var.
var defaultPort = 8080

func main() {
	// 1. Полная форма с явным типом и значением
	var host string = "localhost"

	// 2. Полная форма без значения — получит нулевое значение
	var retryCount int

	// 3. Короткое объявление (только внутри функций)
	appName := "BookmarkFlow"
	timeoutSec := 30
	tlsEnabled := false

	fmt.Println(appName, host, defaultPort, retryCount, timeoutSec, tlsEnabled)
}
```

Вывод программы:

```text
BookmarkFlow localhost 8080 0 30 false
```

Почему в Go тип пишется **после** имени (`var host string`), а не до (`string host`), как в C или Java? Так код читается естественным порядком слева направо: «переменная `host` типа `string`». Когда дойдём до функций и сложных типов, вы оцените, насколько это упрощает чтение сигнатур.

Короткое объявление `:=` — главный рабочий инструмент внутри функций. Компилятор сам выводит тип по правой части: `"BookmarkFlow"` даёт `string`, `30` — `int`, `false` — `bool`. При этом тип остаётся таким же жёстким, как при `var`.

Когда использовать `var`, а когда `:=`?
* **`var`** — на уровне пакета (где `:=` запрещён синтаксисом), либо когда нужно явно задать нулевое значение (`var count int`) или нестандартный тип (`var limit int64 = 100`).
* **`:=`** — во всех остальных случаях внутри функций, когда начальное значение известно сразу.

## Нулевые значения (*zero values*)

В Go **не существует** неинициализированных переменных с мусором из памяти. Если вы объявили переменную через `var` без значения, компилятор гарантированно заполняет её **нулевым значением** своего типа:

| Тип | Нулевое значение |
|---|---|
| Все числовые (`int`, `float64`, `uint8`…) | `0` |
| Логический (`bool`) | `false` |
| Строка (`string`) | `""` (пустая строка) |

Это снимает целый класс ошибок: счётчик `var attempts int` сразу готов к `attempts++`, а строка `var prefix string` — к склейке, без лишних проверок «а не пусто ли там в памяти». В следующих модулях вы увидите, что в Go даже сложные типы из стандартной библиотеки стараются делать полезными прямо в своём нулевом состоянии.

## Три частые ошибки компилятора с переменными

Не бойтесь этих сообщений — вы встретите их десятки раз в первую неделю, и каждое из них бережёт от реального бага.

**Ошибка 1. Переменная объявлена, но не используется:**

```go
func main() {
	title := "Документация Go"
	// title нигде не читается
}
```

```text
./main.go:4:2: declared and not used: title
```

Компилятор считает неиспользуемую локальную переменную ошибкой (точно так же, как лишний `import`). Чаще всего это опечатка: вы хотели передать `title` в функцию, но забыли.

**Ошибка 2. Повторное `:=` для уже существующей переменной:**

```go
port := 8080
port := 9090 // compile error: no new variables on left side of :=
```

Оператор `:=` **объявляет** новую переменную, а `=` **присваивает** новое значение существующей. Вторая строка должна выглядеть как `port = 9090`.

Тонкость: `:=` разрешён, если слева указано несколько переменных и **хотя бы одна** из них — новая в текущей области видимости:

```go
host, port := "127.0.0.1", 8080
port, errMsg := 9090, "" // ОК: errMsg — новая переменная, port просто обновляется
```

**Ошибка 3. `:=` вне функции:**

```go
version := "0.1.0" // compile error: syntax error: non-declaration statement outside function body
```

На уровне пакета каждая строка верхнего уровня обязана начинаться с ключевого слова (`var`, `const`, `func`, `type`).

## Константы и счётчик `iota`

Если значение известно ещё до запуска программы и не должно меняться во время работы, объявляйте его через **`const`**:

```go
const (
	MaxBookmarks = 1000
	DefaultHost  = "127.0.0.1"
	SecondsInDay = 24 * 60 * 60
)
```

У констант в Go есть важное отличие от переменных: их значения вычисляются **во время компиляции**, поэтому константой может быть только число, строка или `bool` — результат вызова функции вроде `runtime.NumCPU()` в `const` положить нельзя. Зато неиспользуемая константа не вызывает ошибки компиляции.

Ещё одна особенность — **нетипизированные константы**. В строке `const limit = 100` у `limit` нет жёсткого типа вроде `int` или `int64`: пока вы не присвоите её конкретной переменной, она хранит «идеальное» число с огромной точностью и свободно подходит к любому совместимому числовому типу.

Для последовательных целочисленных кодов в Go есть встроенный генератор **`iota`** — внутри блока `const` он начинает с `0` и увеличивается на `1` с каждой новой строкой:

```go
const (
	StatusPending = iota // 0
	StatusActive         // 1
	StatusArchived       // 2
)
```

С помощью `iota` удобно задавать и степени двойки (например, размеры памяти: `1 << 10` = 1024 байта), с этим мы ещё встретимся в Модуле 5.

> [!check] Проверь понимание
> Что выведет следующий фрагмент кода и скомпилируется ли он вообще?
> ```go
> var count int
> var label string
> var ready bool
> fmt.Printf("%d %q %t\n", count, label, ready)
> ```
>
> Скомпилируется без ошибок и выведет `0 "" false`. Все три переменные получили предсказуемые нулевые значения своих типов.

## Практика

**Упражнение 1 (Базовое). Проследи вывод (Code Tracing).**  
Не запуская компилятор, предскажите, что напечатает программа, а затем проверьте себя:

```go
package main

import "fmt"

const (
	LevelDebug = iota
	LevelInfo
	LevelWarn
	LevelError
)

func main() {
	var attempts int
	attempts = attempts + 2
	attempts++
	fmt.Println(attempts, LevelDebug, LevelWarn, LevelError)
}
```

> [!solution] Показать решение
> Программа выведет:
> ```text
> 3 0 2 3
> ```
> `attempts` стартует с нулевого значения `0`, затем становится `2`, а `attempts++` увеличивает его до `3`. В блоке `const` значения `iota` равны `0`, `1`, `2`, `3` соответственно.

**Упражнение 2 (Практическое). Карточка закладки без лишних переменных.**  
Напишите программу `main.go`, в которой с помощью `const` задано имя приложения `"BookmarkFlow"` и максимальная длина названия (`80`), а с помощью `:=` и `var` — данные одной закладки: `id` (`1`), `title` (`"Спецификация Go"`), `url` (`"https://go.dev/ref/spec"`), `visits` (нулевое значение через `var`) и `archived` (нулевое значение через `var`). Выведите все поля одной понятной строкой.

> [!solution] Показать решение
> ```go
> package main
>
> import "fmt"
>
> const (
> 	appName      = "BookmarkFlow"
> 	maxTitleSize = 80
> )
>
> func main() {
> 	id := 1
> 	title := "Спецификация Go"
> 	url := "https://go.dev/ref/spec"
> 	var visits int
> 	var archived bool
>
> 	fmt.Println(appName, "| лимит названия:", maxTitleSize)
> 	fmt.Println("#", id, title, "->", url, "| переходов:", visits, "| архив:", archived)
> }
> ```
> Обратите внимание: переменные `visits` и `archived` объявлены через `var`, потому что нам нужны именно их нулевые значения `0` и `false`.

**Упражнение 3 (Со звёздочкой \*). Что сломается?**  
В этом коде три независимые ошибки, связанные с переменными и константами. Найдите все три и объясните, почему компилятор откажется их пропустить:

```go
package main

import "fmt"

appPort := 8080

func main() {
	const timeout = 5
	timeout = 10

	retries := 3
	retries := 4
	fmt.Println(appPort, timeout)
}
```

> [!solution] Показать решение
> 1. `appPort := 8080` — короткое объявление запрещено вне тела функции (нужно `var appPort = 8080`).
> 2. `timeout = 10` — константе нельзя присвоить новое значение (`cannot assign to timeout`).
> 3. `retries := 4` — переменная `retries` уже объявлена в этой области (`no new variables on left side of :=`), к тому же `retries` нигде не используется (`declared and not used: retries`).
>
> Исправленный вариант:
> ```go
> package main
>
> import "fmt"
>
> var appPort = 8080
>
> func main() {
> 	const timeout = 5
> 	retries := 3
> 	retries = 4
> 	fmt.Println(appPort, timeout, retries)
> }
> ```
